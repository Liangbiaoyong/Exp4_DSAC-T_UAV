## 模块职责

### 1. 环境层 (`env/quadrotor_env.py`)

| 类 | 职责 |
|---|------|
| `Quadrotor2DKinematics` | 四旋翼点质量模型: 惯性延迟 + 二次阻力 + 限速 (x, y, vx, vy, ax, ay) → 状态更新 |
| `PointCloudPerception` | 120° 扇形射线 → 指数衰减概率 → 高斯噪声 → 鬼点 |
| `OccupancyGrid` | 160×160 栅格 → Bresenham 更新 → 随 UAV 移动 |
| `KalmanFilterCV` | 恒定速度卡尔曼滤波 (x, y, vx, vy) |
| `UAVAgent` | 单架无人机的状态、感知、建图聚合 |
| `MultiQuadrotorEnv` | Gym 环境：重置、步进、碰撞检测、奖励计算 |

### 2. 网络层 (`networks.py`)

| 类 | 输入 | 输出 | 用途 |
|---|------|------|------|
| `CNNEncoder` | 160×160 栅格 | 多维特征 | 共享视觉编码器 |
| `Actor` | 栅格+点云+状态+动态目标 | (mu, sigma) | 输出高斯策略 |
| `DistributedCritic` | 栅格+点云+状态+动态目标+动作 | 32 分位数 × 2 | 分布价值评估 |
| `Temperature` | — | alpha | 自动熵调节 |

### 3. 算法层 (`dsac_t.py`)

| 类 | 职责 |
|---|------|
| `ReplayBuffer` | 固定容量经验回放 (100K, uint8 压缩) |
| `DSACTAgent` | 算法主控：select_action / update / save / load |

### 4. 训练层 (`train.py`)

- 多环境并行训练
- 周期性 checkpoint 保存（10 分钟）
- 周期性 demo 渲染（5 分钟，每 5 分钟自动渲染演示片段到 `demo_clips/`）
- 支持 `--load_checkpoint` 断点续训

### 5. 演示层 (`demo.py`)

- 2×2 面板可视化（世界图 + 栅格 + 点云 + 统计）
- 预测未来轨迹（1-2 秒）
- 输出 GIF/MP4 文件

## 数据流

```
UAV 感知 → 点云 + 栅格 + 状态 → Actor → 动作
                                      ↓
环境 step ← 动作应用到运动学 ← 碰撞检测
    ↓
奖励 + 新观测 → ReplayBuffer → DSAC-T 更新
                                    ↓
                         Actor / Critic / Alpha 优化
```

## 奖励结构

总奖励 `r(s, a)` = `step_penalty` + `guidance_reward` + `goal_reward` + `collision_penalty`

| 分量 | 值 | 说明 |
|------|-----|------|
| `step_penalty` | -0.01 | 每步固定时间惩罚 |
| `guidance_reward` | 0.1 × (d_prev − d_curr) | 稠密导向奖励：靠近目标→正，远离→负 |
| `goal_reward` | +10 | 到达目标 |
| `collision_penalty` | −C_coll × β | 碰撞惩罚，β 随成功次数递增 |

### 导向奖励（Guidance Reward）

提供稠密学习信号，解决稀疏奖励问题：

- 每 **靠近目标 1m** → +0.1 奖励
- 每 **远离目标 1m** → -0.1 惩罚

UAV 在收到稀疏的 +10 目标奖励之前，就能通过导向奖励学习趋近目标行为。

## 碰撞处理

碰撞后 UAV 不会结束 episode，而是**就地重置到随机安全位置**（目标保持不变）：

1. 施加碰撞惩罚 `-C_coll × β`（β 随成功次数递增）
2. 尝试 50 次在安全区域生成新位置（避开障碍物边界）
3. 重置位置、随机航向、巡航速度
4. 清除占用栅格（避免旧地图干扰）
5. 重新计算到目标的距离（防止导向奖励跳变）

## 经验回放缓冲区

- 容量：**100K** transition（原为 1M，实测可用）
- 内存压缩：grid_map 以 **uint8** 存储（乘 255），取出时除以 255 恢复 float32
  - 单条 transition：~26.5 KB（grid_map 26KB + 其余）
  - 总内存：~2.65 GB（可运行）

### Alpha（温度系数）

Alpha 是 SAC/DSAC-T 中的**温度参数**，控制探索与利用的平衡：

| α 值 | 策略行为 | 阶段 |
|------|---------|------|
| 高（~1.0） | 随机探索，动作噪声大 | 训练初期 |
| 低（~0.1） | 确定执行，动作噪声小 | 训练后期 |

- Alpha 通过梯度下降**自动学习**（Temperature 网络），目标是使策略熵匹配目标熵 -2.0
- `alpha_loss = α · (log_prob + target_entropy)` 的梯度驱动 α 收敛到合适值
- 训练开始时 α≈1.0（`exp(log_alpha_init=0)`=1.0），随训练逐渐下降

## 物理模型

### 滚转转弯模型（Bank-Angle Turn）

真实固定翼无人机转弯靠**滚转产生向心力**，取代了旧的自行车模型：

```
转弯速率:  psi_dot = g · tan(φ) / v
转弯半径:  r = v² / (g · tan(φ))
```

| 参数 | 值 | 说明 |
|------|-----|------|
| `max_bank_angle` | 0.25 rad (~14°) | 最大滚转角 |
| `g` | 9.81 m/s² | 重力加速度 |

物理特性：
- **高速→转弯平缓**（半径 ∝ v²，物理正确）
- **低速→转弯灵活**（适合避障）
- 巡航速度 3m/s 时：转弯半径 ≈ 3.6m

## 安全目标生成

新目标生成时确保远离障碍物和边界：

- 离障碍物中心 ≥ 3m
- 离世界边界 ≥ 3m
- 50 次随机尝试后失败则回退到世界中心
