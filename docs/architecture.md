## 模块职责

### 1. 环境层 (`env/fixedwing_env.py`)

| 类 | 职责 |
|---|------|
| `FixedWingKinematics` | 自行车模型运动学 (x, y, psi, v) → 状态更新 |
| `PointCloudPerception` | 120° 扇形射线 → 指数衰减概率 → 高斯噪声 → 鬼点 |
| `OccupancyGrid` | 160×160 栅格 → Bresenham 更新 → 随 UAV 移动 |
| `KalmanFilterCV` | 恒定速度卡尔曼滤波 (x, y, vx, vy) |
| `UAVAgent` | 单架无人机的状态、感知、建图聚合 |
| `MultiFixedWingEnv` | Gym 环境：重置、步进、碰撞检测、奖励计算 |

### 2. 网络层 (`networks.py`)

| 类 | 输入 | 输出 | 用途 |
|---|------|------|------|
| `CNNEncoder` | 160×160 栅格 | 多维特征 | 共享视觉编码器 |
| `Actor` | 栅格+点云+状态+动态目标 | (mu, sigma) | 输出高斯策略 |
| `DistributedCritic` | 栅格+点云+状态+动态目标+动作 | 32 分位数 × 2 | 分布价值评估 |
| `Temperature` | — | alpha | 自动熵调节 |

### 3. 算法层 (`dsac_t.py`)

| 类 | 职责 |
|---|------|
| `ReplayBuffer` | 固定容量经验回放 (1M) |
| `DSACTAgent` | 算法主控：select_action / update / save / load |

### 4. 训练层 (`train.py`)

- 多环境并行训练
- 周期性 checkpoint 保存（10 分钟）
- 周期性 demo 渲染（5 分钟）

### 5. 演示层 (`demo.py`)

- 2×2 面板可视化（世界图 + 栅格 + 点云 + 统计）
- 预测未来轨迹（1-2 秒）
- 输出 GIF/MP4 文件

## 数据流

```
UAV 感知 → 点云 + 栅格 + 状态 → Actor → 动作
                                      ↓
环境 step ← 动作应用到运动学 ← 碰撞检测
    ↓
奖励 + 新观测 → ReplayBuffer → DSAC-T 更新
                                    ↓
                         Actor / Critic / Alpha 优化
```

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 世界大小 | 50×50m | 连续空间 |
| 无人机数量 | 5 | 可配置 |
| 感知范围 | 15m | 最大探测距离 |
| 栅格分辨率 | 0.25m/cell | 160×160 |
| 折扣因子 γ | 0.99 | 长期回报权重 |
| 学习率 | 3e-4 | AdamW |
| 批大小 | 256 | 训练批次 |
| 分位数数量 | 32 | 分布式 Critic |
